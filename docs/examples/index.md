# Examples

Training recipes for the Expected Decoding Rounds (EDR) paper experiments. Each corresponds
to a directory under `examples/` with a `run.sh` script that runs on a single GPU (the paper
used one NVIDIA H200; one B200 or RTX PRO 6000 also works) with a global batch of 96.

| Example | Drafter | Target | Objective | Initialization |
|---------|---------|--------|-----------|----------------|
| [qwen3-4b-dspark-edr](../../examples/qwen3-4b-dspark-edr/) | DSpark | Qwen3-4B | EDR | deepseek-ai/dspark_qwen3_4b_block7 |
| [qwen3-4b-dspark-e2e](../../examples/qwen3-4b-dspark-e2e/) | DSpark | Qwen3-4B | E2E | deepseek-ai/dspark_qwen3_4b_block7 |
| [qwen3-8b-dfly-cpt-edr](../../examples/qwen3-8b-dfly-cpt-edr/) | DFly | Qwen3-8B | EDR | AngelSlim/Qwen3-8B-DFly-Block8 |
| [qwen3-8b-dfly-cpt-e2e](../../examples/qwen3-8b-dfly-cpt-e2e/) | DFly | Qwen3-8B | E2E | AngelSlim/Qwen3-8B-DFly-Block8 |

Sample the training data first with
[generate_training_data](../../examples/generate_training_data/) from the same training config
(so it uses exactly the config's `dataset.target_sampling`), then train. The DSpark checkpoint import is described in
[qwen3-4b-dspark-edr](../../examples/qwen3-4b-dspark-edr/). Offline MAL evaluation is in
[examples/eval](../../examples/eval/).

## Data

The recipes train on Open-PerfectBlend with responses regenerated by the target model
(`tools/regenerate_perfectblend.py`). See [Data Preparation](../basic_usage/data_preparation.md)
for format details.
